# Инструкции для агентов

- Начни с [Readme.md](Readme.md) и [REQUIREMENTS.md](REQUIREMENTS.md). Запуск сервера описан в [server/README.md](server/README.md). Сверяй состояние проекта с кодом и результатами проверки. [Макет B](docs/hud-reference.png) задаёт оформление Android.
- Сохраняй ARCore источником кадров и позы камеры для AR-экрана. Используй одну геометрию отображения для изображения камеры, касаний и проекции 3D-якорей. Подключай другой источник кадров только для отдельного режима.
- Обрабатывай модель вне потока отрисовки. Сопоставляй её результаты с кадром, на котором выполнен анализ. При потере трекинга скрывай метку до восстановления.
- Сохраняй интерфейс B и русские пользовательские строки в ресурсах Android. Ручную метку используй для проверки геометрии без модели.
- После изменений запускай `./gradlew :app:assembleDebug :app:lintDebug` или `.\gradlew.bat :app:assembleDebug :app:lintDebug`. Для AR проверяй постановку и удержание метки на физическом телефоне с ARCore. В отчёте указывай, что удалось проверить фактически.
- Версии зависимостей берутся из Gradle. Сборочные каталоги, локальные настройки SDK и ключи подписи должны оставаться вне истории Git.
