# KST Pump в Figma

Локальный плагин создаёт 19 редактируемых экранов по текущему Android UI. Сборка и установка зависимостей не нужны. Храните `manifest.json` и `code.js` в одной папке.

## Импорт

1. На Windows или macOS откройте файл в **Figma Desktop → Figma Design** с правом редактирования.
2. Нажмите правой кнопкой на холст и выберите **Plugins → Development → Import plugin from manifest…**. Откройте [manifest.json](manifest.json).
3. Запустите **Plugins → Development → KST Pump — экраны осмотра**. На текущей странице появятся секции «Осмотр», «Меню и диалоги» и «Компоненты».
4. Выберите фрейм «Вход» и нажмите **Present**, чтобы пройти прототип. Повторный запуск добавляет новый комплект справа от имеющихся слоёв.

На Arch Linux можно редактировать готовый файл в браузере. Для первого запуска локального плагина откройте этот же файл в официальной Figma Desktop на Windows или macOS. [Инструкция Figma по локальным плагинам](https://help.figma.com/hc/en-us/articles/360042786733-Create-a-classic-plugin-for-development)

Если Figma попросит зарегистрировать ID плагина, создайте в **Plugins → Development → New plugin** шаблон **Run once**, затем скопируйте его `id` в комплектный `manifest.json` и повторите импорт.

## Как редактировать

- В секции «Компоненты» меняйте оформление основных, контурных и текстовых кнопок. Чтобы изменить текст одной кнопки, выберите её экземпляр и отредактируйте свойство «Подпись».
- Нижние карточки и диалоги используют Auto Layout. Текст, отступы и содержимое можно редактировать отдельно на каждом экране.
- Чтобы подложить кадр насоса, выберите прямоугольник «Фон камеры — замените заливку кадром» и задайте заливку **Image**. Дуга, QR-ориентир, стрелка и подпись метки лежат поверх отдельными слоями.
- Прототип использует статичные демоданные, включая пример AR-метки и отчёта. Поля ввода в прототипе служат для редактирования макета. Правки макета переносятся в [Compose](../../app/src/main/java/com/arengineering/inspection/InspectionScreen.kt) отдельным изменением.
