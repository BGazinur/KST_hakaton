# AR Engineering

Android-прототип осмотра насоса с HUD варианта B. Деморежим проводит инженера от входа и идентификации оборудования до осмотра узлов и отчёта. На телефоне с ARCore можно отдельно проверить ручную метку, которая закрепляется на видимой поверхности.

[API интерфейса](docs/UI_API.md) описывает подключение авторизации, каталога, анализа датчиков, CV и отчётов.

[Плагин для Figma](design/figma/README.md) создаёт редактируемые экраны и прототип осмотра.

Требования к сборке, телефону и будущей интеграции модели описаны в [REQUIREMENTS.md](REQUIREMENTS.md). Контекст для агентов находится в [AGENTS.md](AGENTS.md), переписка и макет — в [docs/CHAT.md](docs/CHAT.md).

## Инструменты

- Kotlin и Jetpack Compose для приложения и интерфейса.
- Google ARCore 1.57.0 для кадров камеры, трекинга по видео и данным IMU, поиска поверхности и 3D-якорей. На поддерживаемых устройствах используется Depth API.
- OpenGL ES 2.0 для вывода видеопотока ARCore.
- Android Studio, Android SDK 36, Android Gradle Plugin 9.2.1 и Gradle Wrapper 9.4.1 для сборки. Можно использовать JDK из Android Studio.
- ADB для установки APK и чтения журналов.

## Запуск

Откройте эту папку в Android Studio, выберите смартфон с поддержкой ARCore и запустите конфигурацию `app`. Разрешите камеру. По запросу установите или обновите Google Play Services для AR.

Для сборки из PowerShell задайте `JAVA_HOME` и `ANDROID_HOME`, если они ещё не настроены, и выполните:

```powershell
.\gradlew.bat :app:assembleDebug :app:lintDebug
```

Отладочный APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Проверка метки

1. Войдите в деморежим и на экране QR откройте «Проверить AR-метку». Наведите камеру на неподвижную деталь с заметной текстурой. Плавно сместите телефон вбок, затем коснитесь конкретной точки на детали.
2. Проверьте, что стрелка указывает на ту же точку при шаге вбок, приближении, смене ракурса и повороте экрана.
3. Кратко закройте камеру или отведите её от детали, затем вернитесь к исходному ракурсу. При потере трекинга метка скрывается. Если трекинг восстановился в текущей сессии, она появляется снова.
4. Коснитесь другой поверхности, чтобы переставить метку, или нажмите «Убрать метку».

Прототип хранит одну ручную метку в текущей AR-сессии. В следующем этапе координаты для постановки меток сможет передавать модель распознавания.
